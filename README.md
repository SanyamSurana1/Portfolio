# Sanyam Surana — Developer Portfolio

A responsive personal portfolio website built with semantic HTML5 and custom CSS, inspired by Samsung One UI design principles.

## 🔗 Live Demo
Visit the deployed portfolio on GitHub Pages: [https://sanyamsurana1.github.io/](https://sanyamsurana1.github.io/)

---

## ✨ Features
- **Samsung One UI-Inspired Design:** Clean layouts, smooth spacing, rounded surfaces, and a polished dark/light color palette.
- **Zero-JavaScript Theme Toggle:** A fully functional dark and light mode switcher implemented natively using a hidden checkbox and the modern CSS `:has()` pseudo-class.
- **Fully Responsive:** Adapts seamlessly across desktop, tablet, and mobile viewports using CSS Grid, Flexbox, and media query breakpoints.
- **Semantic HTML Structure:** Built using proper semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) for optimized accessibility and SEO.
- **Accessibility Considerations:** Includes support for `prefers-reduced-motion` and custom focus states.

---

## 🛠️ Built With
- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox, CSS Grid, CSS animations)
- **Google Fonts** (DM Sans & Space Grotesk)
