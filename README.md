# Sanyam Surana — Portfolio Website

A responsive personal portfolio built with plain HTML and CSS. The design takes inspiration from Samsung One UI through rounded surfaces, calm spacing, readable typography, and a restrained charcoal / sage / warm terracotta palette.

## Run it
1. Extract the ZIP.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a browser.

## Theme toggle
The dark/light switch is implemented with a checkbox and CSS `:has()` selector. No JavaScript is used. Use a modern browser for `:has()` support.

## Personalize before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB`
- `YOUR_LINKEDIN`

Review education and project descriptions for accuracy. The Agrover and Smart Door Lock cards are presented as project/concept spotlights; edit them to reflect your exact contribution. Add real repository or demo URLs when available.

## Concepts to prepare for viva
- Semantic HTML (`header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS custom properties and the box model
- Flexbox and CSS Grid
- Sticky positioning and `z-index`
- Hover transitions, transforms, and `@keyframes`
- Media queries and responsive breakpoints
- Checkbox + label interaction and `:has()` for the CSS-only theme toggle
- `prefers-reduced-motion` for accessibility

Google Fonts load online; fallback fonts are included.
